An open-world crime game in the browser: a city on foot and by car, traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, and a HUD with a minimap. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
